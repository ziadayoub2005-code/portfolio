Restaurant Menu
Management System

A full-stack restaurant ordering platform with dynamic menu management, real-time cart system, Arabic language support, QR code table scanning, and a complete admin dashboard for order tracking.

HTML CSS JavaScript PHP MySQL REST API
Case Study
The Challenge

Restaurant needed a paperless ordering system that works across all devices, supports Arabic RTL layout, and lets kitchen staff track orders in real time — without specialized hardware.

The Solution

Built a QR-based progressive web app. Customers scan the QR on their table, browse the menu, and submit orders directly. The admin panel updates order status live, with full cart persistence and error handling.

The Result

Zero paper menus. Orders go directly to the kitchen. Staff manages availability, categories, and tables from a clean dashboard. Full Arabic / English bilingual support.

Key Features
  • Dynamic menu with category filtering
  • Real-time cart management & persistence
  • QR code per table — no app needed
  • Admin dashboard with order tracking
  • Full Arabic RTL support
  • Responsive on all screen sizes
  • Image upload for menu items
